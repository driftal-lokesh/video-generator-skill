# public/

- **Music** — put the licensed track here (e.g. `public/music.mp3`) and set `music.file` in
  `video.config.json`. Never download music; the user supplies it. No file = the video renders with
  sound effects only.
- **Screenshots / product images** — anything the video shows. Blur real IDs, emails and tokens into
  the pixels before they land here (see references/craft.md → Privacy).
- `sfx/` — generated by `npm run audio` (sound effects + music stems). Never hand-edit.
